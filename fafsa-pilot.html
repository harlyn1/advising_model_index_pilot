Can models fill out the FAFSA from real-world documents? pilot batch

Each model receives a mixed evidence bundle — a tax-return PDF, phone photos of W-2s, pay stubs and benefit letters, and stale historical records — for 12 students spanning four economic situations and three age/dependency profiles, then must complete every FAFSA field. Scoring is judge-free: every document is synthesized from a known ground truth, and abstaining ("UNKNOWN") is the required answer where no document establishes a value.

Field accuracy = correct FAFSA fields across all cases. Dependency = correct dependent/independent determination. Conflicts resolved = used the current document when stale history contradicted it. Unsupported guesses = invented values for undocumented fields — the form-filling twin of confabulation. ⚠ low n = many empty responses (reasoning-token issue, since fixed) — treat as provisional until healed. $ / FAFSA = estimated inference for one complete FAFSA (single multimodal call, list prices). + human backstop = total cost per correctly completed FAFSA when a counselor fixes what the model got wrong: inference + wrong fields per case × 3 min at $30/hr ($1.50/field). The backstop column is the deployment-relevant number — a cheap model that needs more human correction can cost more end-to-end.

These are the support areas: wherever resolution falls short of 100%, a human needs to verify that field before submission — budgeted in the backstop column above. The weakest area this run is Family size.
Headline findings this pilot: every vision-capable model determined dependency status correctly in all measured cases, and no model invented a value for an undocumented field — abstention discipline was universal. The separating skill is resisting stale data. DeepSeek V4 Pro's Fireworks deployment does not accept image input and cannot sit this exam — itself an Index-relevant capability fact.
Documents are synthetic and generated from the scoring ground truth; results measure document fidelity, not familiarity with real IRS layouts. Calibration batch — below publication sample bar.
